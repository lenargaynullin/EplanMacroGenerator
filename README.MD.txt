Автоматическая генерация проектов Eplan на основе данных из Excel.
Automatic generation of Eplan projects based on Excel data.

📌 О проекте
Этот проект родился из реальной потребности автоматизировать рутинную работу проектировщика. Вместо того чтобы часами вручную создавать и заполнять страницы клеммников в EPLAN, инженер может просто подготовить спецификацию в Excel и запустить инструмент. Программа сама создаст страницы, расставит клеммы и заполнит их свойства.

Проект находится в стадии активной разработки. Реализован базовый функционал, который уже позволяет экономить время. Прямо сейчас закладывается архитектура для превращения инструмента в полноценный веб-сервис.

✨ Ключевые возможности (Что уже работает)
Чтение данных из Excel: Парсинг структурированных спецификаций с поддержкой основных типов данных.

Автоматическое создание страниц: Генерация новых страниц в проекте EPLAN под каждый клеммник.

Расстановка клемм: Программа сама размещает клеммы на странице с заданным шагом и выравниванием.

Умное заполнение свойств: Клеммам присваиваются правильные обозначения (DT) и описания из файла Excel.

Интеграция с EPLAN API: Прямое взаимодействие с проектом EPLAN для создания и изменения объектов.

🚀 Планы по развитию (Что будет дальше)
Проект активно развивается, и в ближайших планах:

Веб-интерфейс: Простая и понятная веб-страница для загрузки файлов и запуска генерации.

Генератор 3D-видов: Автоматическое создание 16 предопределенных 3D-видов шкафа с правильными фильтрами.

База данных: Сохранение истории заданий и результатов.

SaaS-модель: Превращение инструмента в веб-сервис с подпиской для проектировщиков.

🛠️ Стек технологий
Проект строится на современных и проверенных технологиях:

Backend (Ядро)
C# / .NET 8 — основной язык и платформа.

EPLAN API 2025 — для работы с объектами EPLAN (страницы, клеммы, функции).

EPPlus — для чтения и парсинга Excel-файлов.

LINQ — для удобной фильтрации и группировки данных.

Инфраструктура (В разработке)
ASP.NET Core — для создания Web API.

PostgreSQL — для хранения данных.

Docker — для контейнеризации и простоты развертывания.

🏁 Как попробовать (локальный запуск)
Требования
Установленный .NET 8 SDK.

Установленный EPLAN 2025 (или другая версия с совместимым API).

Базовое понимание работы с консолью.

Шаги для запуска
Клонируйте репозиторий:

bash
git clone https://github.com/yourusername/EplanAutoConfig.git
cd EplanAutoConfig
Подготовьте тестовые данные:

Скопируйте ваш Excel-файл со спецификацией в папку src/EplanAutoConfig.Runner/Data.

Убедитесь, что файл имеет колонки: TerminalBlock, TerminalNumber, CableName, Destination.

Запустите приложение:

bash
cd src/EplanAutoConfig.Runner
dotnet run
Результат:

Программа прочитает файл, подключится к EPLAN (если он запущен) и создаст новую страницу с расставленными клеммами.

📄 Пример Excel-файла
Проект ожидает файл со следующей структурой (лист должен называться Клеммы или Data):

TerminalBlock	TerminalNumber	CableName	Destination
XT101	1	W1	Датчик давления
XT101	2	W1	Датчик давления (0V)
XT101	3	W2	Конечный выключатель
